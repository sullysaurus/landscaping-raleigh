## Interpretation rules

- Search volume is an approximate U.S. monthly estimate, not Raleigh-only demand unless the phrase includes Raleigh.
- Ads competition is not organic keyword difficulty.
- CPC is directional commercial-intent evidence, not a revenue forecast.
- Local zero-volume phrases can still be valuable when the problem and conversion path are clear.
- One strong page owns close variants; do not create a separate thin page for each wording.
- Search Console impressions, clicks and qualified inquiries should supersede this third-party snapshot once enough data accumulates.
